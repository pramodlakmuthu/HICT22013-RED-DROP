## 🚀 Key Features

* **Real-World Medical Eligibility Checker:** Validates donor criteria based on National Blood Transfusion Service (NBTS) safety guidelines (Age, Weight, Last donation interval, and medical history).
* **25-District Blood Bank Locator:** Fast lookup for blood banks and regional donor centers across all 25 districts in Sri Lanka.
* **Slot Booking & Dynamic Confirmation Slip:** Interactive pop-up reservation system that generates a confirmation slip with donor details and appointment specs.
* **Single-Page Application (SPA) Architecture:** Clean view-switching logic built with modular HTML and an external JavaScript file (`script.js`).
